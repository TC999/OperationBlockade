# OperationBlockade
Decompilation of Operation Blockade

## 构建说明 (Build Instructions)

### 系统要求 (System Requirements)
- Windows 操作系统 (Windows OS)
- Visual Studio 2022 或更高版本 (Visual Studio 2022 or later)
- Windows SDK 10.0

### 编译步骤 (Build Steps)

1. **打开项目 (Open Project)**
   ```
   使用 Visual Studio 打开 OperationBlockade.sln
   Open OperationBlockade.sln with Visual Studio
   ```

2. **选择构建配置 (Select Build Configuration)**
   - Debug|Win32 - 32位调试版本 (32-bit Debug)
   - Release|Win32 - 32位发布版本 (32-bit Release)
   - Debug|x64 - 64位调试版本 (64-bit Debug)
   - Release|x64 - 64位发布版本 (64-bit Release)

3. **构建项目 (Build Project)**
   - 方法1: 按 `Ctrl+Shift+B` 或点击菜单 "生成" > "生成解决方案"
   - Method 1: Press `Ctrl+Shift+B` or click "Build" > "Build Solution"
   
   - 方法2: 使用命令行 (Use Command Line)
   ```cmd
   msbuild OperationBlockade.sln /p:Configuration=Release /p:Platform=Win32
   ```

4. **运行程序 (Run Program)**
   ```
   编译成功后，可执行文件将生成在:
   After successful compilation, the executable will be in:
   - Debug 版本: Debug/OperationBlockade.exe
   - Release 版本: Release/OperationBlockade.exe
   ```

### 常见问题 (Common Issues)

#### 编译错误 (Compilation Errors)
如果遇到编译错误，请确保：
If you encounter compilation errors, make sure:
- 已安装 Visual Studio C++ 工具集 (Visual Studio C++ toolset is installed)
- 已安装 Windows SDK (Windows SDK is installed)
- 项目平台工具集版本正确 (Project platform toolset version is correct)

#### 平台工具集 (Platform Toolset)
本项目配置使用 v143 (Visual Studio 2022)。如果使用其他版本的 Visual Studio，可能需要修改项目属性中的平台工具集。
This project is configured to use v143 (Visual Studio 2022). If using a different Visual Studio version, you may need to modify the platform toolset in project properties.

### 注意事项 (Notes)
- 这是一个反编译项目，代码由 Hex-Rays 反编译器生成
- This is a decompilation project, code generated by Hex-Rays decompiler
- 建议在 Release 配置下构建以获得最佳性能
- Recommended to build in Release configuration for best performance
